◆ ADC_init()

void ADC_init ( )

Initialize the ADC subsystem.

Configures the ADC with the following settings:

  • Reference voltage: AVcc
  • Prescaler: 128 (ADPS2:0 = 111)
  • Enables ADC
  • Performs initial dummy read for accuracy
Note
This function must be called before using any other ADC functions.
The function waits for any ongoing conversion to complete before initialization.
