void ENGINE_init ( )

Initializes motor control system.

Sets up pins for H-bridge motor control and enables both motor pairs. Configures all control pins as outputs and enables motor power.

Returns
nothing, this function can't fail.
Note
After initialization, motors are enabled but stopped (direction pins not set)
