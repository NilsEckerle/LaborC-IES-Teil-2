Sets a specific bit in a register to 1

Parameters
regThe register or variable to modify
bitThe bit position to set (0-based indexing, 0 = LSB)
Note
This is implemented as a do-while(0) macro to ensure proper statement behavior when used in conditional statements. The macro is safe to use in all contexts where a single statement is expected.

uint8_t status = 0x00; // 00000000 SET_BIT(status, 3); // Sets bit 3: 00001000 (0x08)

#ifndef BIT_FUNCTIONS
#define BIT_FUNCTIONS
#define SET_BIT(reg, bit) do {reg |= (1 << bit);} while(0)
#define UNSET_BIT(reg, bit) do {reg &= ~(1 << bit);} while(0)
#define IS_BIT_SET(reg, bit) ((reg & (1 << bit)) ? 1 : 0)
#endif // !BIT_FUNCTIONS
