{\footnotesize\ttfamily void ADC\+\_\+init (\begin{DoxyParamCaption}{ }\end{DoxyParamCaption})}



Initialize the ADC subsystem. 

Configures the ADC with the following settings\+:
\begin{DoxyItemize}
\item Reference voltage\+: AVcc
\item Prescaler\+: 128 (ADPS2\+:0 = 111)
\item Enables ADC
\item Performs initial dummy read for accuracy
\end{DoxyItemize}

\begin{DoxyNote}{Note}
This function must be called before using any other ADC functions. 

The function waits for any ongoing conversion to complete before initialization. 
\end{DoxyNote}
