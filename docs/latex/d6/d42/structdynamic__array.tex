\doxysubsection{Detailed Description}
Dynamic array structure for storing data. 

This structure implements a resizable array that can store pointers to any type of data. It automatically manages memory allocation and provides type-\/safe access through macros.

\begin{DoxyWarning}{Warning}
This struct doesn\textquotesingle{}t work with char$\ast$ strings directly! Use the provided macros for proper type handling.
\end{DoxyWarning}
\begin{DoxyNote}{Note}
The array stores void pointers, allowing storage of any data type. Size is limited to 255 elements due to uint8\+\_\+t size field. 
\end{DoxyNote}
