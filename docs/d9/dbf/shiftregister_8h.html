void SHIFT_push_state ( uint8_t  bitstring_to_push)

Converts line follower detection state to shift register output.

Parameters
bitstring_to_pushthe last 3 bits gets pushed, starting at the MSB
Returns
nothing, this function can't fail
Note
The function pushes 3 bits to the shift register representing Left, Middle, Right sensor states in that order. Each push sends one bit, with 1 = sensor active, 0 = sensor inactive.
